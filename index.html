Apps by Plain Point Studio

Lot 01Live

Life Balance Index (openslbi.plainpoint.net in a new tab)

A self-assessment dashboard for eight aspects of life. Answer a research-backed baseline once, then check in weekly with rough measured quantities (activity, sleep, savings, learning) and eight A–F grades and a single Balance Index move only as much as the numbers justify. Weekly, not a daily logging ritual.

Openlbi.plainpoint.net

  • Data stays on this device
  • No account
  • English + ไทย
  • Open source

Lot 05Live

Runaway (opensseehighxb.github.io/Runaway in a new tab)

A shared run log for a small circle of friends. Post distance, time and notes; everyone sees a live leaderboard and a zero-sum baht loss pool. The one app here that needs a server, because the whole point is that your friends see it.

Openseehighxb.github.io/Runaway
