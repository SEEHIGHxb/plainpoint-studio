Two recommended rules are switched off in `.htmlvalidate.json`, both on purpose.

`doctype-style` wants `<!DOCTYPE html>`. The sheet is written in lowercase throughout and
HTML treats the token case-insensitively, so this is a house-style preference, not a defect.

`no-redundant-role` wants `role="list"` dropped from every `<ul>`. It is redundant only in
the abstract. Safari strips list semantics from a `<ul>` whose `list-style` is `none`, which
is every strip row and every policy list on this site, so VoiceOver stops announcing "list,
4 items". The explicit role puts the semantics back.
